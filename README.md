# Landings de Rentahop

Cada carpeta en la raíz de este repositorio es una landing independiente,
publicada automáticamente en landings.rentahop.com/<nombre-de-la-carpeta>

Para añadir una nueva landing:
1. Crea una carpeta nueva en la raíz con el nombre que quieras usar en la URL
   (por ejemplo, "herramientas" para landings.rentahop.com/herramientas).
2. Sube dentro su index.html y demás archivos.
3. Sube los cambios a GitHub (Add file > Upload files, o con git push).
4. Cloudflare desplegará automáticamente los cambios en unos segundos.
